# 📝 Python To-Do List (CLI Version)

A simple command-line **To-Do List Application** written in Python.  
You can **add**, **view**, and **delete** tasks — all from your terminal.  
Perfect for beginners practicing Python basics like lists, loops, and functions.

---

## 🚀 Features
- ➕ **Add Task** — Add a new task to your list.  
- 📋 **View Tasks** — Display all your saved tasks.  
- ❌ **Delete Task** — Remove a specific task by its number.  
- 💾 **Persistent Tasks (Optional)** — Extend the code to save tasks in a file.  
- 🧠 **Pure Python** — No external libraries required.
